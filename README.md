# cds-sme

Hệ thống đánh giá mức độ chuyển đổi số cho doanh nghiệp vừa và nhỏ (SME).

## Công nghệ

- Frontend: React, Vite, Tailwind CSS
- Backend: Node.js, Express, TypeScript
- Database: SQL Server 2022 qua Docker

## Ghi chú

- Sao chép file `.env.example` tương ứng thành `.env` trước khi chạy local.
- Không commit `.env`, `node_modules`, build output hoặc dữ liệu cục bộ.
